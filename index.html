Accounts

Sync across devices

One private repository, every device
  1. On GitHub, create a private repository, for example trading-journal
  2. Go to Settings → Developer settings → Fine-grained tokens
  3. Generate one for only that repository, with Contents: Read and write
  4. Paste both below, then press Sync now

The token stays on this device and never travels in the journal file or a backup. Trades, signals, goals and accounts sync; your Discord link and this token do not.

Discord

Send your daily review to a channel

One-click posting only works when you open this app from the file on your own computer. The shared online link runs in a sandbox that blocks outside sites, so there use Copy on the daily review and paste it into Discord.

  1. In Discord, right-click the channel you want → Edit Channel
  2. Open Integrations → Webhooks → New Webhook
  3. Press Copy Webhook URL
  4. Paste it below and press Save
